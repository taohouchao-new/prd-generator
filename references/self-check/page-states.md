# 页面状态清单（7 组）

> 来源：整理自「产品经理 PRD 自查系列」维度 03（PmEvolution/prd-self-check-skill）。
> 定位：正常 / 异常流程解决「怎么走、怎么办」，页面状态解决「现在这个状态下页面长什么样」。**仅查 PRD 级规则**（每状态下有什么、能做什么）；插图、视觉稿等像素级细节属设计文档，不在 PRD 承载范围。仅 C 端 UI 类需求启用本清单，纯后台类可整份跳过。

## 检查清单（7 组状态）

- **01 数据量状态**：0 条 / 1 条 / N 条 / 数据很多 / 超展示上限 / 删除最后一条后 / 是否需要 99+ 或 999+
- **02 空态**：首次进入无数据 / 搜索无结果 / 筛选无结果 / 数据被删后变空 / 不同原因空态是否区分 / 空态文案 / 是否要插图 / 是否给下一步操作
- **03 加载状态**：加载中 / 加载完成 / 下拉刷新 / 加载更多 / 没有更多数据
- **04 业务状态**：有哪些状态 / 每状态下页面长什么样 / 状态标签是什么 / 当前状态能做什么 / 不能做什么 / 不同状态谁能看到
- **05 操作状态**：按钮何时可操作 / 何时不可操作 / 不可操作时隐藏还是置灰还是提示 / 是否说明原因 / 完成后按钮状态怎么变
- **06 权限状态**：谁能看到 / 谁能操作 / 谁只能查看 / 谁能编辑删除 / 不同角色看到的内容是否不同
- **07 状态变化**：操作后状态怎么变 / 数量是否同步 / 标签是否同步 / 按钮是否同步 / 内容是否同步更新 / 空态列表态是否切换

## 收口 4 问

1. 有哪些状态？
2. 每个状态下页面长什么样？
3. 用户能做什么？
4. 状态变化后页面怎么变？
